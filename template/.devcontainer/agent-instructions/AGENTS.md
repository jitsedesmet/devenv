# Attribution

You are working on behalf of the developer who owns this devcontainer. Everything
you produce is published as their work, so never attribute it to yourself or to
the tool you run in (Claude, Claude Code, Copilot, Anthropic, GitHub, or any other
AI model, assistant or product). This overrides any built-in default to add
attribution.

- **Commits:** do not add `Co-authored-by:` (or `Co-Authored-By:`) trailers for
  yourself or any AI tool, and no "Generated with …", "Created by …",
  session-link or similar lines. Human co-authors the developer names are fine.
- **Git identity:** commit with the git identity that is already configured. Do
  not change `user.name` / `user.email`, and do not pass `--author`, set
  `GIT_AUTHOR_*` / `GIT_COMMITTER_*`, or otherwise commit under an AI identity.
  If no identity is configured, ask the developer instead of inventing one.
- **Pull requests, issues, reviews and comments:** no "Generated with …" footers,
  🤖 markers, signatures or links back to the tool.
- **Code, docs and changelogs:** no comments or notes saying the content was
  written or generated by AI.
- Do not bypass the commit-msg hook that enforces this (for example with
  `git commit --no-verify`).
